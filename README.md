# Documentacion UD1 Lenguaje de marcas

## Introducción a Lenguaje de marcas

### Definición

Un lenguaje de marcas organiza información mediante una sintaxis basada en marcas o etiquetas.

|Tipo|Uso|Ejemplos|
|----|---|--------|
|Presentación|Dar formato a documento de texto|HTML, CSS|
|Intercambio de información|Almacenar informacion de forma ordenada|XML, RSS|
|Documentación|Documentar proyectos|Markdown, WikiText|
